### ✨ Why Pinkie?

- 🌸 **Gentle Ergonomic Contrast**: Deep charcoal-plum text (`#453B43`) rested against a soft milky background (`#FFFDFD`) completely eliminates harsh blue light and glare.
- 🎨 **Rainbow Bracket Pair Colorization**: Brackets smoothly colorized with sweet strawberry, lavender, jade mint, and coral peach hues.
- 🎀 **Pastel Status Bar & Tabs**: Distinctive rose-milk status bar, delicate borders, and glowing active tab indicators.
- 🌙 **Pinkie Dark Included**: A cozy night-owl companion palette featuring dreamy midnight violet backgrounds with glowing pastel pink highlights.

### 📦 Installation

#### Method 1: Install via VSIX (Direct & Offline)
1. Download the latest [`pinkie-for-vscode.vsix`](pinkie-for-vscode.vsix) release file.
2. In **VS Code**, open the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`).
3. Click the `...` menu at the top right of the Extensions panel.
4. Select **Install from VSIX...** and select `pinkie-for-vscode.vsix`.
5. Select your theme: Press `Ctrl+K Ctrl+T` -> Choose **Pinkie Light** or **Pinkie Dark**.

#### Recommended Settings for Kawaii Aesthetics:
```json
{
  "workbench.colorTheme": "Pinkie Light",
  "workbench.iconTheme": "pinkie-icons",
  "editor.bracketPairColorization.enabled": true,
  "editor.guides.bracketPairs": true,
  "editor.cursorBlinking": "smooth",
  "editor.cursorSmoothCaretAnimation": "on",
  "editor.fontFamily": "'JetBrains Mono', 'Cascadia Code', 'Fira Code', monospace"
}
```
